# 仲介bot（PayPay代金預かり方式）

管理画面の **仲介** タブ（セキュリティタブの右）から設定します。設定はサーバーごとにD1へ保存され、`.env` は不要です。

## 取引の流れ

| 段階 | 誰が | 内容 |
|---|---|---|
| ⓪ 仲介費 | 両者 | 「相手が負担 / 割り勘 / 自分が負担」を選ぶ。割り勘・自分が負担は送金リンクを入力（金額を確認、まだ受け取らない）。負担者が一致したら受け取り、不一致なら選び直し。仲介費0円ならスキップ |
| ① 金額の合意 | 両者 | それぞれ金額を入力。一致でスタート、不一致なら中止＆チャンネル削除 |
| ② 役割の選択 | 両者 | 買い手／売り手を選ぶ。重複したら選び直し |
| ③ 送金 | 買い手 | PayPay送金リンクをモーダルで提出（チャンネルには表示されない）。パスコード付きのリンクはパスコードも入力、なしなら空欄 |
| 預かり | bot | リンクの金額・状態を確認 → 一致すれば運営PayPayで即受け取り。違えば差し戻し |
| ④ 受け渡し | 両者 | チャット解放。チャンネル内で商品を渡す |
| 完了 | 両者 | 片方が「取引完了」（`/complete`）→ もう片方に「同意する / まだ続ける / 通報」を求める。返事がなければ設定時間後に自動同意 |
| ⑤ 支払い | bot | 運営PayPayから売り手宛の送金リンクを作成し、売り手だけが押せるボタンで渡す |
| 通報 | スタッフ | `/report` または「通報」ボタン。代金凍結 → スタッフが「売り手へ支払う / 買い手へ返金する」→ botが送金リンクを作成 |

パスコード間違いなど、受け取りを断られてもリンクがまだ「受け取り待ち」のまま（＝お金が動いていない）ときは、本人にもう一度提出してもらいます（仲介費・代金それぞれ3回まで）。割り勘で片方だけ受け取れた場合、その分は受け取り済みのまま、もう片方だけ再提出します。

運営PayPayのログイン切れ、受け取れたかどうか分からないとき、再提出が3回を超えたときは、スタッフ通知チャンネルに判断ボタン付きで通知され、手動対応に切り替わります。処理の途中で15分以上止まった取引も、スタッフに一度だけ通知します。

## 管理画面のタブ

| タブ | 設定できること（旧 `.env`） |
|---|---|
| パネル設置 | パネルの設置・更新、タイトル・説明文、仲介費（`MEDIATION_FEE`）、スタッフロール（`STAFF_ROLE_ID`、複数可）、取引チャンネルのカテゴリ（`TRADE_CATEGORY_ID`）、スタッフ通知チャンネル（`STAFF_CHANNEL_ID`）、同時取引数の上限、中止・完了後にチャンネルを消すまでの時間 |
| 実績 | 実績を送る部屋（`RESULT_CHANNEL_ID`）、チャンネル名の前半（`RESULT_CHANNEL_BASE`）、投稿・件数表示のON/OFF、取引ログの保存先（`LOG_CHANNEL_ID`）、集計と最近の取引 |
| ブラックリスト | ブラックリストのロール（`BLACKLIST_ROLE_ID`、複数可）、アカウント作成日数・サーバー参加日数の下限 |
| 支払い | 運営PayPayのログイン（SMS認証）、取引金額の下限・上限、自動同意までの時間（`AUTO_AGREE_HOURS`） |

`DISCORD_TOKEN` / `GUILD_ID` はWorkerのSecretsとサーバー選択で置き換わり、`DB_PATH` / `LOG_DIR` はD1とログチャンネルへの投稿で置き換わります。

## スラッシュコマンド

- `/complete` 取引完了を申請（取引チャンネル内）
- `/report` トラブルを通報（取引チャンネル内）
- `/check メンバー` 買い手実績・売り手実績を確認（本人にだけ表示）

パネルを設置すると自動で登録されます。

## Cloudflare版での違い

- Gatewayに常駐しないため、自動同意・チャンネル削除・実績チャンネル名の更新は1分ごとのCronで行います（最大1分ほど遅れます）。
- 取引ログは、チャンネル削除の直前に全発言をテキストにしてログチャンネルへ投稿します。8MBまでの添付ファイルは一緒に再アップロードし、それ以外はURLを記録します。全文を取得するにはBOTの **Message Content Intent** をONにしてください。
- 実績チャンネル名の変更はDiscordの制限（10分に2回）に合わせて5分以上あけます。
- Security Botを使っている場合、チャンネル削除などの前に短時間のMaintenance Leaseを取得します。

## 注意点

- 非公式APIはPayPayの仕様変更で突然動かなくなることがあり、運営アカウントが制限・凍結されるリスクもあります。取引額の上限を決め、残高を溜めすぎないようにしてください。
- 支払い用の送金リンクは受取人が受け取らないと期限切れで運営アカウントに戻ります。
- 送金リンク・パスコードはD1に暗号化して保存し、受け取り後は削除します。
