# Open-source acknowledgements

This project is an independent implementation that intentionally reuses open-source
libraries and design ideas instead of copying private Discord bots.

Architecture and feature-design references:

- qwertyvan/Discord-Bot — MIT. TypeScript, discord.js, Fastify, Postgres/Prisma,
  Discord OAuth dashboard architecture.
- nawaf1t/discord-security-bot — MIT. Audit-log based anti-nuke, action windows,
  trust/allow-list model.
- SapphDevelopment/discord-captcha-bot — MIT. Verification flow and Discord
  verification-bot structure.

Runtime libraries such as discord.js, Fastify, React, Vite, pg and Zod retain
their respective upstream licenses.

No private/proprietary bot source code is included.
